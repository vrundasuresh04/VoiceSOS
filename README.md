# 🚀 VoiceSOS — Say Help. Stay Protected.

A voice-triggered women safety application built during a 24-hour hackathon to provide instant emergency assistance using simple voice commands.

---

## 💡 Problem

In emergency situations:
- Users don’t have time to unlock phones
- Multiple steps delay help
- No evidence is captured

---

## 🔐 Solution

VoiceSOS enables users to trigger an SOS alert by simply saying:

👉 **"help help"**

The system instantly detects distress and activates emergency response.

---

## ✨ Features

- 🎙️ Voice-triggered SOS detection  
- ⏱️ 10-second cancel window (false alarm protection)  
- 📍 Real-time location sharing  
- 🎧 20-second automatic voice recording  
- 🚨 Instant alert to trusted contacts  
- 📊 AI-based confidence detection  

---

## ⚙️ How It Works

1. User says **"help help"** or presses SOS button  
2. System detects distress  
3. 10-sec cancel timer starts  
4. If not cancelled → emergency mode activates  
5. Location is shared  
6. 20-sec audio recording starts  
7. Alert sent to contacts  

---
